# 스토리 (v2 — 전면 개편)

> 이전 안(지구 에너지 위기·12막·엔딩 3분기)은 **폐기**. 이 문서가 스토리의 유일한 기준이다.
> 규칙 하나: **이야기는 그림과 애니메이션으로만 전달한다. 글은 읽기 싫으니까 없거나, 있어도 아주 짧게.**

## 1. 한 줄 요약
**사과 모양 행성에 반해서 사고 싶었던 도둑이, 돈을 벌려고 행성을 훔치다가, 마지막 한탕을 성공시키고, 이제 사러 가는 길에 — 날아온 칼에 사과 행성을 잃는다.**

슬픈 엔딩이지만 게임은 끝나지 않는다. 엔딩 이후엔 자유롭게 논다.

## 2. 연출 원칙 (무문자 규칙)

| 규칙 | 내용 |
|---|---|
| 스토리·튜토리얼·지시는 글 금지 | 아이콘, 말풍선 속 그림(이모지/스프라이트), 표정, 카메라 연출, 소리로만 전달 |
| 글이 허용되는 곳 | ① 퀴즈(문제·보기·해설) ② 상점 품목 이름·가격 ③ 도감 설명 — **전부 짧게** |
| 글자 수 상한 | 라벨은 **한 단어/이모지 위주**, 안내 문구는 한 줄(12자 내외). 긴 대사 금지 |
| 컷신 | 항상 **건너뛰기(⏭)** 가능. 길이 5~25초. 대사 없음, 말풍선엔 그림만 |
| 진행 표시 | 숫자·문장 대신 **사과 아이콘이 채워지는 게이지** 등 시각 표현 |
| 접근성 | 색만으로 구분하지 않기(모양 병행), 사운드는 보조 |

> 퀴즈는 이 게임에서 거의 유일하게 글을 읽는 부분이다. 해설은 **1문장**을 기본으로 줄인다(`CURRICULUM.md` 8.3의 "2문장 이내"를 더 줄임).

## 4. 비트 시트 (시간순)

플레이 타임 약 10~11시간 중 배치. 시각은 목표치(경제 재설계 후 보정).

| # | 시각 | 비트 | 화면에서 보이는 것 (글 없음) |
|---|---|---|---|
| 1 | 0:00 | **첫눈에 반함** | 시작 직후 카메라가 먼 곳의 사과 행성을 비춘다 → 주인공 눈에 하트 💗 → 사과 행성 위에 **가격 아이콘(💰 큰 숫자 대신 금화 더미)** → 주인공이 주머니를 뒤집으면 텅 빔 💨 → 의지 표정 😤. 이게 동기 |
| 2 | 0:05~ | **훔쳐서 번다** | 기본 루프: 행성을 훔쳐 **암시장**에 판다. 화면 상단에 **사과 게이지**(모은 돈 → 사과가 채워짐) |
| 3 | ~0:40 | **들킨다** | 암시장 거리. 평범한 행인 하나가 물건을 훔치는 나를 지켜본다 → 클로즈업으로 눈이 **번쩍(금빛)** → 정체(수호신) 실루엣이 잠깐 비침 → 사라짐. **이 사람이 위장한 수호신** |
| 4 | 0:40~9:30 | **숨바꼭질** | 수호신들이 맵 곳곳에 숨어 있다(바위·행인·그림자 뒤). **내가 쳐다보면 숨고, 눈을 떼면 슬금슬금 다가온다.** 가끔 시야 구석에서 발견하는 재미 |
| 5 | ~9:30 | **마지막 한탕 발견** | 최종 구역에서 **삼연 행성**을 발견. 3개가 붙어 반짝인다. 주인공이 침을 꿀꺽 + 사과 게이지가 가득 찰 만한 가격 표시 |
| 6 | ~9:40 | **추격전** | 훔치려는 순간, 뒤에서 **참다 참다 폭발한 수호신**이 쫓아온다(화면 빨갛게, 발소리, 지진). 기지까지 달린다 |
| 7 | ~9:50 | **성공 = 산 것** | 기지에 도착하면 삼연 행성이 기지에 놓이고, 이것이 곧 **확보(구매 성공)**. 수호신은 문 앞에서 멈춰 분해하는 표정 |
| 8 | ~9:55 | **큰돈** | 암시장에서 삼연 행성을 팔자 금화가 산더미. 사과 게이지가 **가득 참 → 사과가 반짝** |
| 9 | ~10:00 | **사러 간다** | 사과 행성을 향해 출발. 화면 끝에 사과가 점점 커진다(신나는 음악) |
| 10 | ~10:05 | **의뢰** | 가는 길에 **의뢰 아이콘(❗+행성 그림)** 이 뜬다. 가볍게 들러 가기로 한다(수락해야 진행, 거부 불가의 "한 군데만 들르자" 연출) |
| 11 | ~10:10 | **엔딩** | 다른 행성을 잡으러 가는 길. 누군가(실루엣)가 칼을 **탁** 쳐서 칼이 빙글빙글 날아간다 → 카메라가 따라가면 **사과 행성에 꽂힘** → 사과가 금이 가며 사라지거나 쪼개짐 → 주인공 😢 → 천천히 줌아웃, 비 오는 연출 → 화면 암전 |
| 12 | 엔딩 후 | **자유 플레이** | 사과 게이지는 비어 있고 사과 자리는 빈 하늘. 이제 마음대로 |

> ⏱ 3번(들킴)은 너무 일찍 나오면 긴장감이 길어지고, 너무 늦으면 숨바꼭질이 짧아진다. 0:40 근처로 시작하고 실제 플레이 타임에 맞춰 조정(❓).

## 5. 핵심 새 메커니즘

### 5.1 시선에 반응하는 수호신 (숨바꼭질)
- **규칙**: 플레이어 카메라가 수호신을 바라보면(시야각 안 + 가림 없음) 수호신은 **즉시 숨는다**(작아지며 사라짐, 위장 오브젝트로 변신). 시선이 벗어나면 **조금씩 접근**한다.
- **위장 대상**: 바위, 상자, 행인 NPC, 전봇대 같은 풍경. 위장했을 때의 **미세한 단서**(눈이 반짝, 그림자가 사람 모양)를 둬서 눈치채는 재미.
- **닿으면**: 기존 `caught()` 처리(돈 손실·행성 빼앗김)에 **경계도(수배) 시스템**을 연결.
- **구현 힌트**: 카메라 전방 벡터와 수호신 방향의 내적 + 레이캐스트로 가림 판정. 접근 속도는 섹터 난이도와 연동. 기존 구역 수호자(추격형)와 **공존**(구역 안=추격형, 섹터 사이=숨바꼭질형) 또는 점진 대체 — ❓ 결정.

### 5.2 위장한 수호신 (정체 공개 장면)
- 암시장 거리의 **평범한 행인 NPC** 중 하나가 진짜 수호신. 평소엔 다른 NPC와 같아 보임.
- 3번 비트에서만 확정 연출. 이후에는 **행인 NPC 중 가끔 수상한 개체**가 있도록(눈 반짝 단서) 일반화.

### 5.3 암시장 (판매 장소)
- 지금은 기지 슬롯에서 `F`로 판다. 이를 **암시장 NPC**와 상호작용하는 방식으로 이동(또는 병행): 행성을 들고 가서 상인에게 → 금화 애니메이션.
- 암시장 장면이 곧 3번 비트의 무대.

### 5.4 삼연 행성 (마지막 한탕)
- 가장 희귀한 행성 **3개가 붙어 있는 특수 둥지**(`kind: 'triple'`). 한 번에 3개를 훔쳐 들어야 하므로 **가방 용량/무게 조건**을 만족해야 훔칠 수 있음(전용 가방 업그레이드가 자연스러운 선행 과제).
- 훔치는 순간 **전용 추격전** 시작(기존 수호자 속도의 배수, 거리·장애물 연출).
- 성공 조건: **기지 도착**.

### 5.5 사과 게이지 (진행 표시)
- 숫자·문장 대신 **사과 아이콘이 채워지는 모양**으로 목표까지 얼마나 모았는지 표시.
- 엔딩 후에는 사과 아이콘이 **빈 자리**(깨진 사과 윤곽)로 바뀜.

## 6. 엔딩 이후 (자유 플레이)

| 가능한 것 | 설명 |
|---|---|
| 자유롭게 돌아다니기 | 모든 구역·포탈 자유 이동, 수호신은 평소대로 |
| 평소처럼 훔치기 | 기본 루프 유지(경제 지속) |
| **집을 산다** | 기지 확장/꾸미기를 **"집"** 으로 연결: 집 종류(텐트 → 오두막 → 우주 주택 → 성), 내부 가구. 돈의 새로운 sink. 사과 대신의 새 목표 |
| 도감/업적/수집 | 남은 도감 채우기, 별조각 등 |
| (선택) 사과 행성 잔해 | 사과가 있던 자리에 **작은 파편/싹**이 있어 쓸쓸한 분위기를 조금 보듬는 장치(❓) |

> "집을 산다"는 사과 행성을 사려던 마음의 대체이자, 엔딩 후 돈 쓸 이유. 상점의 기지 슬롯 확장·꾸미기와 통합 설계.

## 7. 시스템 요구사항 (구현 에이전트용)

### 7.1 컷신 디렉터 (`game/cutscene*.ts`)
- 타임라인 기반: `[{t, camera:{to,look,fov}, actor:{id,anim,pos}, bubble:{who,icon}, fx:{...}, sound}]`.
- 말풍선은 **그림만**(이모지/아이콘 스프라이트). 텍스트 노드 금지(`bubble.text` 필드를 아예 두지 않는다).
- 건너뛰기 버튼, 일시정지(`paused()`와 통합), 중간 저장 지점 없음(짧아서).
- 세이브: `S.story = { beat: number, seen: {…} }`로 비트 진행 저장(`core/save-schema.ts` v6 마이그레이션).

### 7.2 월드 요소
- **사과 행성**: 전용 지오메트리(구에 오목 + 꼭지 + 잎), 후광, 항상 원경에 표시(청크와 무관).
- **암시장 장소** + 상인 NPC + 위장 가능한 행인 NPC 군중.
- **삼연 행성 둥지** + 전용 추격 시스템.
- **칼 이벤트**: 스크립트 연출(포물선 + 회전 + 충돌 이펙트).

### 7.3 시스템 (레지스트리에 등록)
- `systems/watcher.ts` (시선 수호신), `systems/story.ts` (비트 진행·트리거), `systems/chase.ts` (삼연 추격).
- 상호작용: 암시장(`kind: 'blackmarket'`), 의뢰판(`kind: 'request'`), 삼연 둥지(`kind: 'triple'`).

### 7.4 UI
- 아이콘 중심 HUD: 사과 게이지, 경계 아이콘(눈 모양), 의뢰 ❗.
- 튜토리얼도 **그림 힌트**(키 모양 아이콘, 화살표, 손가락 애니메이션).

## 8. 이전 안과의 차이 (정리)

| 항목 | 이전 안 | 새 안 |
|---|---|---|
| 동기 | 지구 에너지 위기(제안만 됨) | **사과 행성에 반해서 사고 싶다** |
| 전달 방식 | 챕터 + 대사 | **그림/애니메이션만, 글은 최소** |
| 구조 | 12막, 엔딩 3분기 | **한 줄기 이야기, 엔딩 1개**(슬픈 엔딩) + 자유 플레이 |
| 수호신 | 구역을 지키는 추격형 | **+ 시선에 숨는 숨바꼭질형 + 위장형** |
| 마지막 | 태양 훔치기 | **삼연 행성 훔치기 → 추격 → 사과 상실** |
| 엔딩 후 | 후일담 모드 | **자유 플레이 + 집 구매** |
| NPC/의뢰 | 텍스트 의뢰 다수 | **아이콘 의뢰**, 암시장 중심 |

## 9. 구역(섹터)과의 연결
- 4번 숨바꼭질은 **전 구역**에서 진행. 구역이 깊어질수록 수호신 수·접근 속도 증가.
- 5번(삼연 행성)은 **마지막 섹터**(가장 희귀 행성 구역)에 배치.
- 섹터 해금의 `챕터` 조건은 **스토리 비트(`S.story.beat`)** 로 대체. 예: "들킴(3) 이후", "삼연 발견(5)".
- 12개 구역 구성과 행성 목록은 `CONTENT_PLAN.md`를 따르되, 12장의 결정에 따라 재편 가능.

## 10. 교육과의 관계
- 스토리는 교육과 **분리**: 이야기를 배우는 게 아니라, 행성을 훔칠 때 푸는 **퀴즈가 교육 부분**.
- 글을 읽기 싫다는 원칙 때문에 퀴즈 문장도 **짧고 직관적**으로(`CURRICULUM.md` 출제 가이드 + 이 문서 2장).
- 이미지 문제(스펙트럼, 그래프 보고 고르기)가 글 문제보다 이 게임 톤에 잘 맞는다 → **그림 기반 문제 비중을 높인다**.
