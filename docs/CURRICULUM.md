### 1.4 unitId 규칙

```
sci{과목번호}-{영역번호}-{묶음번호}
 과목번호: 1 = 통합과학1, 2 = 통합과학2
 영역번호: 성취기준 코드의 가운데 두 자리와 동일(01, 02, 03 → 1, 2, 3)
 묶음번호: 해당 영역 안에서 이 문서가 임의로 나눈 순번 (교과서 중단원 아님)
예) sci1-2-1 = 통합과학1 · 물질과 규칙성 · 스펙트럼과 우주 초기 원소
```

- **중단원은 교육과정 고시에 없다**(고시는 영역→성취기준 구조). 교과서마다 중단원 이름이 다르므로, 이 프로젝트의 `mid`는 성취기준·내용 요소를 기준으로 **본 문서가 정한 묶음**이다.
- 문제 태깅은 `unitId` 하나 이상 + 필요 시 성취기준 코드(예: `10통과1-02-03`)를 같이 붙인다.
- JSON의 추가 필드 `legacy2015`: 2015 개정과의 대응 메모(추정 포함).

## 3. 핵심 개념 · 공식 · 수치 (통합과학 수준)

수식은 교육과정에 "정성적으로"라 명시되지 않은 것만 계산형 문제에 쓴다. 계산 허용 정도는 **[추정]**이며 교과서·모의평가 경향에 따른다(이번에 교과서 본문은 열람하지 못함).

| 영역 | 핵심 개념/공식 | 수치·사실 | 비고 |
|---|---|---|---|
| 시공간·단위 | 속력 v = 거리/시간, 밀도 ρ = m/V, 단위 환산 | 빛의 속력 c ≈ 3.0×10⁸ m/s, 1광년 ≈ 9.46×10¹² km (광년은 **거리**) | 기본량: 시간·길이·질량·전류·온도 [확인, 해설] |
| 우주 초기 원소 | 선스펙트럼은 원소의 지문 | 우주에서 가장 많은 원소는 H, 그다음 He | 질량비 약 74%/24% 등 수치는 출제 지양 [추정] |
| 별의 진화 | 수소→헬륨 핵융합(주계열), 이후 더 무거운 원소, 초신성 | 철보다 무거운 원소는 초신성 폭발로 생성(고시 해설 문구 그대로 사용) | 철까지의 핵융합 단계 서술은 교과서 따라 상이 [미확인] |

## 4. 흔한 오개념 (오답 보기·해설 소재)

**근거 수준**: 온실효과/오존층 혼동은 고1 137명 대상 연구 [확인, 2차 출처: 한국과학교육학회지 2000]. 중력 관련 교과서 간 불일치 지적 [확인, 2차 출처]. 나머지는 과학교육 일반에 널리 알려진 오개념으로 **[추정: 이번 조사에서 개별 논문 확인 못함]**.

|---|---|---|
| 온실효과 | 온실효과 = 오존층 파괴 / 온실효과는 나쁜 것 | 온실효과는 자연 현상(없으면 지구 평균 기온이 훨씬 낮음). 문제는 **강화**. 오존층은 자외선 차단과 관련 [확인] |
| 지구온난화 | 지구온난화 때문에 산성비가 내린다 | 별개의 환경 문제 [확인(연구에서 혼동 보고)] |

| 별 | 태양은 곧 폭발한다 | 수십억 년 후 적색거성 단계 |

## 5. 난이도 3단계 기준

| 단계 | 기준 | 보기·유형 | 예시 개념 |
|---|---|---|---|
| 기초 (basic) | 용어·정의·분류, 단일 개념 1단계 추론, 중학교 연계 수준 | 상식 오답 1~2개 | 별 에너지원은 핵융합, 지구시스템 5권역, 이온/공유 구분, 산화=산소 얻음 |
| 표준 (standard) | 개념 2개 연결 또는 자료(그래프/표/그림) 해석, 간단 계산 | 오개념 오답 포함 | 선스펙트럼으로 원소 판정, I=FΔt로 힘 비교, 온실효과 메커니즘, 먹이 사슬 변화 |
| 심화 (advanced) | 통합 추론(2영역 이상), 낯선 상황 적용, 다단계 판단 | 보기 모두 그럴듯, 근거 선택 | 행성 g 비교로 점프 높이 추론, 대멸종 자료 해석, 효율이 다른 발전 방식 비교 |

- 심화도 **교육과정 범위 안**이어야 한다(범위 밖 지식이 풀이에 필요하면 안 됨).

## 7. 우주 사실을 쓸 때의 주의점

### 7.1 물리량 기준값 (NASA Planetary Fact Sheet에서 직접 확인 [확인])

- 가스 행성의 "표면 중력"은 **1기압 구름 꼭대기 기준**의 값이다(고체 표면 없음). 평균 온도도 동일 기준. 문제에 "표면"이라 쓰면 주의 [NASA 표 각주 취지, 상세 각주 미확인].
- 명왕성: 2006년 IAU가 "왜소행성"으로 분류 [추정: 이번 조사에선 개별 확인 안 함, 널리 알려진 사실]. 행성 개수를 묻는 문제는 8개로 통일.

### 7.2 계산·표현 규칙

| 항목 | 올바른 식/단위 | 흔한 오류 |
|---|---|---|
| 표면 중력 | g = GM/R² (G = 6.674×10⁻¹¹ N·m²/kg², 단위 m/s²) | R을 지름으로 넣음 / km·m 혼용 |
| 무게 | W = mg (단위 N), 질량은 kg | "kg이 무게" / 달에서 질량 감소 |
| 궤도 속력(원궤도) | v = √(GM/r), r는 **행성 중심에서 거리** | 고도를 r로 사용 |
| 탈출 속도 | v_esc = √(2GM/R) = √2 × v_orbit(표면) | **물체 질량에 무관**인데 질량 관계 서술 / "빨아들이는 속도" 오해 |
| 슈바르츠실트 반경 | r_s = 2GM/c² (지구 약 9 mm, 태양 약 3 km — 교육과정 밖, 배경) | 블랙홀이 '모든 것을 빨아들인다'는 서술 |
| 광년·AU | 1 ly ≈ 9.46×10¹² km, 1 AU ≈ 1.5×10⁸ km | 광년을 시간으로 서술 |
| 단위 | 지수 표기 일관, 유효숫자 2~3자리, 단위 표기 필수 | 단위 누락, 10의 거듭제곱 오류 |

### 7.3 사실 서술 시 지켜야 할 것
- **교육과정 밖 사실은 "문제 해결에 필수"가 되면 안 된다.** 소재·배경 설명에만 쓰고, 정답 판단은 교육과정 내 개념으로 하게 설계.
- 외계행성(WASP-76b 철 비, 케플러/TESS 후보 등) 세부는 **이번 조사에서 웹 확인을 하지 않음 [미확인]**. 사용 전 NASA Exoplanet Archive / 논문 확인. 확인 전에는 "관측 결과가 ~를 시사한다" 표현.
- 화성 과거 수권, 엔셀라두스·유로파 바다, 금성 과거 해양, 타이탄 대기 같은 "진행 중 연구" 항목은 단정 금지.
- 블랙홀 "시간 지연"은 일반 상대성 이론이라 교육과정 밖 → 읽을거리/흥미 설명까지만, 문제로는 "중력 단원 연결 개념: 중력이 매우 강해 빛도 빠져나오지 못한다" 수준의 사실 선택지만.
- 행성/위성 "표면 중력 몇 배" 같은 계산 문제는 7.1 값을 그대로 사용하고, 출처 표기.

## 8. 문제 출제 가이드라인

### 8.1 좋은 객관식의 조건
1. **한 문항 = 한 성취기준(또는 한 unitId) = 한 가지 판단.** 서로 다른 개념을 섞지 않는다.
2. **정답 하나가 명백**하고, 교육과정/고시 해설 범위 안에서 판정 가능.
3. 문두는 질문이 분명하고 짧게(권장 2문장 이내). **우주 소재는 맥락으로만** 쓰고, 소재를 몰라도 풀리게 한다.
4. 보기 길이·문체·구조를 비슷하게. 정답이 가장 길거나 구체적이면 안 된다.
5. "모두 정답", "정답 없음", "ㄱ,ㄴ" 합답은 사용 지양(게임 UI 호환).
6. 이중 부정 금지. "옳지 않은 것"은 허용하되 굵게/명시.
7. 그림·표 없이도 풀 수 있게(UI가 텍스트 중심이라면).

### 8.2 오답 보기 만드는 법
| 방법 | 예 |
|---|---|
| 4장 오개념 활용 | "에어백은 충격량을 줄인다" |
| 비슷한 용어 | 핵융합↔핵분열, 광년(거리)↔시간 |
| 정답의 일부만 맞음 | 인과 방향 뒤집기 |
| 계산 오류 유도 | 단위 환산 누락, 지름/반지름 혼동 |
| 범위 확대 | "항상", "모든", "반드시" |
| 같은 범주 다른 항목 | 5개 권역 중 엉뚱한 것 |
- 터무니없는 보기 금지(최소 하나는 그럴듯). 정답 위치 균등 분포.
- 오답이 **교육과정 밖에서는 참**일 수 있는 보기 금지(예: 대학 수준에서 옳은 서술을 오답으로 둠).

### 8.3 해설 작성 규칙
1. 첫 문장에 정답 근거(핵심 개념) → 2~3문장으로 왜 오답인지.
2. 오개념 오답에는 어떤 오개념인지 한 줄.
3. 관련 `unitId`/성취기준 코드는 메타로 둔다(본문에 남발 금지).
4. 단위·수식은 본문과 동일 표기. 천체 수치는 7.1에서 가져온다.
5. 어조는 짧고 단정적. 길면 "더 알아보기" 한 줄로 교육과정 밖 배경(선택 사항, 사실 확인된 것만).

### 8.4 피해야 할 것
| 금지 | 이유 |
|---|---|
| 2.3의 "다루지 않는" 항목 출제 | 교육과정 이탈 |
| 교육과정 밖 심화(상대론, 케플러, 허블 계산, pH 계산, 산화수, 엔탈피) | 난이도 이탈 |
| 모호한 표현("대체로", "보통", "크다") 만으로 정답 판단 | 정답 논쟁 |
| 최신 논쟁 중 사실(외계 생명 징후, 철 비 해석, 암흑물질 등) | 오개념 위험 |
