# 콘텐츠 기획서 — "무엇을 만들 것인가"

[ROADMAP.md](ROADMAP.md)가 **언제/어떤 순서로** 만드는지라면, 이 문서는 **실제로 무엇이 들어가는지**를 구체적인 이름·숫자로 적는다.
방향을 잡기 위한 **초안**이다. 마음에 안 드는 부분은 고치면 되고, 확정된 부분만 구현으로 넘어간다.
교육 범위는 [CURRICULUM.md](CURRICULUM.md)를 따른다(출제 가능/불가 경계 포함).

> 표기: ⚠ = 사실 확인 필요(천체 수치·발견 연도 등은 구현 전에 NASA 등으로 검증), ✅ = 확정(11장 결정표의 추천 기본값을 적용함. 바꾸려면 11장부터 고친다)

## 0. 한 문장 컨셉과 목표 시간

**"우주 도둑이 되어 12개 구역의 행성 80개를 훔치고, 마지막엔 태양을 노린다. 문제를 풀어야 훔칠 수 있다."**

- 목표 플레이 타임: **약 10~11시간**(현재는 실측 10분). 새 요소(새 장비·새 위험·새 이야기)를 **10분마다 하나씩** 만난다.
- 설계 원칙: 시간은 맵 크기가 아니라 ①진행 곡선 ②할 거리의 종류 ③장비 해금 ④이야기로 채운다.

### 시간 배분 (합계 약 10.5h)
| 활동 | 시간 | 설명 |
|---|---|---|
| 메인 진행 (섹터 돌파·행성 수집) | 4.5h | 훔치기 → 기지 → 상점 업그레이드 반복 |
| 스토리 연출 + 아이콘 의뢰 | 1.5h | 컷신(건너뛰기 가능) 12개 이내, 섹터마다 아이콘 의뢰 2~3개 |

의뢰 유형:

- **관측**: 스펙트럼 그림을 보고 대기 성분 판단(퀴즈, 이미지 캔버스로 생성).
- **특정 행성 훔치기**: 조건 만족(변이, 질량 등).
- **기지 수리**: 라이벌 침입 후 복구.

## 7. 수집·레이스·업적

- **별조각**: 구역당 20개 숨김(총 240) → 모으면 도감 보너스·장식 해금.
- **링 레이스**: 구역별 1코스(점프팩/호버보드/우주선 사용), 기록 서버 리더보드(`/api/score`).
- **업적 50개** 예: 첫 도둑질 / 변이 ×3 행성 보유 / 경계도 ★5 생존 / 무피격 클리어 / 도감 100% / 오답 복습 20회 / 모든 하이스트 클리어 / 자유 플레이 후 집 4종 구매 …
- 기지 건물: **관측소**(도감 수익 +), **연구소**(성장 시간 −), **금고**(라이벌 도난 방지), **격납고**(차량 보관).

## 8. 경제·상점 sink (돈이 계속 쓸 곳)

| 항목 | 현재 | 확장 |
|---|---|---|
| 기지 칸 | 10 | **30** (구역별 증설) |
| 신발 | Lv10 | **Lv30** |
| 스프링 | 10종 | **25종** |
| 가방 | 3단계 | **6단계** |
| 장비 | 없음 | 방호복·방열복·방한복·헬멧 등급 |
| 차량 | 없음 | 6종 + 업그레이드 3트랙 |

- 핵심 문제: 현재 행성 수익 `가격/25`가 후반 폭주 → 경제 재설계 에이전트가 `data/pacing.ts`에서 조정. 목표는 위 "누적 시각" 표.

## 9. 교육 연결 (게임 안에서 배우는 방식)

- **행성 퀴즈**(훔칠 때 1문항): 행성 소재와 연결. 현재 25문항 → 행성마다 최소 1문항, 구역 난이도별 변형.
- **문(시험)**(3문항 중 2): 구역 단원 주제. 난이도 1~5가 구역과 함께 상승.
- **관측 의뢰**: 이미지 기반 문제(스펙트럼, 그래프).
- **도감 해설**: 행성 설명에 교육과정 연결 개념 1줄("이 행성은 ○○ 단원의 □□ 예시").
- **오답 복습**: 틀린 문제가 `S.notes`에 쌓이고 교수 NPC에서 재도전(정답 시 보상).
- **문제 은행 목표**: 210문항(30개 단원×7, 최소 200), 30개 단원 균등(단원당 약 7문항), 난이도 3단계(기초 40% / 표준 40% / 심화 20%).
- **표시 원칙**: 해설은 짧고 정확하게(**1문장**, STORY 2장·QUIZ_BANK 기준), 교육과정 밖 사실은 소재로만 사용(`CURRICULUM 7.3`).
