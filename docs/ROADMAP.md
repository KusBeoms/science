# 로드맵 — 10시간+ 오픈월드 확장

승인된 계획 요약 (상세 설계는 아래 원칙 참고). 단일 파일 시절 계획을 TypeScript/C++ 구조에 맞게 이어간다.

## 원칙
- "맵만 넓히면" 이동 시간만 늘어난다 → 진행 곡선(경제)·할 거리 종류·이동 수단·스토리 마디로 10시간을 채운다.
- 콘텐츠(행성·문제·미션)는 `client/src/data/`의 **데이터 테이블**로 추가한다(코드 변경 최소화).

## 마일스톤
| 단계 | 내용 | 상태 |
|---|---|---|
| M0 | 세이브 v4(`stealPlanet4`, v3 이어받기) · 경제 시뮬레이터 · **TS+C++ 구조 리팩터링** | 완료 (세이브 v4 · TS 클라이언트 · C++ 서버 · compose). 브라우저 실기 검증은 미실시 |
| M1 | 월드 청크/섹터 시스템, 섹터 4→8개 | 미착수 |
| M2 | 이동 수단(호버보드/우주선) + 빠른 이동 | 미착수 |
| M3 | 수배 시스템 + 하이스트 | 미착수 |
| M4 | 스토리 챕터 + NPC/서브 미션 프레임워크 | 미착수 |
| M5 | 행성 80종 + 문제 200문항 데이터 투입 | 미착수 |
| M6 | 레이스/수집/업적/환경 위험 | 미착수 |
| M7 | 밸런싱(10h 목표 검증) + 버그 정리 | 미착수 |

## 경제 시뮬레이터 결과 (현재 콘텐츠)
`index.html` 데이터 기준 단순 시뮬(탐욕 구매 정책): 상점 아이템을 모두 사는 데 약 **1.75시간**.
→ 현재 콘텐츠는 2시간 안팎이면 소진되므로 M1~M5의 확장이 필요하다. (시뮬 한계: 도감/구역 해금 조건이 단순화되어 구역 해금 시간은 신뢰하기 어렵다.)

## 세이브 버전
- v3 키 `stealPlanet3` → v4 키 `stealPlanet4`. v4가 없으면 v3를 읽어 이어받는다.
- v4 신규 필드: `ver, chapter, wanted, vehicle, ach, coins, playSec`.
