# 로드맵 — 10시간+ 오픈월드 확장

승인된 계획 요약 (상세 설계는 아래 원칙 참고). 단일 파일 시절 계획을 TypeScript/C++ 구조에 맞게 이어간다.

## 원칙
- "맵만 넓히면" 이동 시간만 늘어난다 → 진행 곡선(경제)·할 거리 종류·이동 수단·스토리 마디로 10시간을 채운다.
- 콘텐츠(행성·문제·미션)는 `client/src/data/`의 **데이터 테이블**로 추가한다(코드 변경 최소화).

## 실측 vs 시뮬레이터 (중요)
- 초기 시뮬레이터(탐욕 구매 정책)는 상점 소진까지 약 1.75시간으로 추정했으나, **사용자 실측은 현재 콘텐츠 전체 약 10분**이다. 시뮬은 6~10배 낙관적이었으므로 **실측값으로 보정하기 전에는 시뮬 결과를 신뢰하지 않는다.**
- 원인(코드): 행성 초당 수익 `inc = price/25` 라서 후반 행성 하나가 수만~수십만/초를 벌어 상점 상한을 순식간에 소진한다. 해금 조건도 시험 통과뿐이라 시간 장벽이 없다.
- 결론: 목표(10시간+ = 현재의 약 60배)는 콘텐츠 양만으로 못 채운다 → **경제 곡선 재설계 + 시간이 걸리는 해금 조건(이동 수단·신발·도감·챕터) + 상점 sink 확대**가 선행 과제다. 경제 수치는 `data/pacing.ts`에 모아 한 곳에서 조정한다.

## 세이브 버전
- v3 키 `stealPlanet3` → v4 키 `stealPlanet4`. v4가 없으면 v3를 읽어 이어받는다.
- v4 신규 필드: `ver, chapter, wanted, vehicle, ach, coins, playSec`.
- v5 (키는 `stealPlanet4` 그대로, `ver: 5`): `unlocked, portals` + 후속용 빈 기본값 `quests, vehicles, heists, collectibles`. `zone` → `unlocked`, `notes` 키 인덱스 → 섹터 id 변환. 체인은 `client/src/core/save-schema.ts`.
