## 2. 아이콘 의뢰 30개

### 2.1 규칙
- **요구 시퀀스**는 화면에 아이콘 줄로만 표시(예: 🌍→📦→🌙). `→`는 순서, `+`는 동시 조건.
- 아이콘 의미(의뢰판 공통 범례): 📦 배달, 🪐 행성 훔치기, 📷 관측(이미지 퀴즈), ☄️ 추격, 🔧 수리, 🧪 샘플, ❓ 퀴즈, ⏱️ 시간제.
- 보상: 🪙 금화(구역 평균 행성 가격 대비 %, 최종값은 `data/pacing.ts`), ⭐ 별조각, 🎁 아이템/장식. 금화는 “평균 가격의 20~60%”를 기준으로 시작한다.
- 교육 연결은 CURRICULUM 단원 id(없으면 주제어). **관측형은 이미지 문제를 우선**(STORY 10장).
- 수락 후 포기 가능, 재수락 가능. 진행도는 `S.quests`에 저장(5장).

## 5. 세이브 필드·데이터 스키마 초안

현행 세이브는 v5(`stealPlanet4` 키, `ver: 5`)이며 `quests, vehicles, heists, collectibles`가 **빈 기본값**으로 이미 있다(ROADMAP). 스토리는 v6에서 `S.story`를 추가할 예정(STORY 7.1)이므로, 이 문서의 필드는 **v6에 함께 넣는 것을 권장**한다(마이그레이션 1회). 체인은 `client/src/core/save-schema.ts`에 추가.

```ts
// data/quests.ts — 정적 데이터 (세이브 아님)
export type QuestKind = 'deliver' | 'steal' | 'observe' | 'chase' | 'repair' | 'quiz' | 'time' | 'move';
export interface QuestStep {
  icon: string;                    // 화면에 보일 아이콘 1개 (예: '📦')
  type: 'goto' | 'steal' | 'quiz' | 'collect' | 'photo' | 'timer';
  target?: string | number;        // 섹터 id / 행성 id / 아이템 id / 포탈 id
  count?: number;
  timeLimitSec?: number;
}
export interface QuestDef {
  id: string;                      // 'Q01'..'Q30'
  sector: number;                  // 0..11
  giver: string;                   // NPC id ('N06' 등)
  kinds: QuestKind[];
  steps: QuestStep[];              // 순서대로 진행
  reward: { coinPct?: number; stars?: number; item?: string };
  eduRef?: string;                 // 'sci2-1-3' 등
  required?: boolean;              // Q13
  prereq?: { beat?: number; quest?: string; sector?: number };
}
export interface AchDef {
  id: string;                      // 'A01'..'A50'
  emoji: string;
  name: string;                    // 짧은 이름 (<= 8자)
  hidden: boolean;
  reward: { coinPct?: number; stars?: number; item?: string; title?: string };
  check: (s: SaveV6) => number;    // 현재 진행값
  goal: number;                    // check() >= goal 이면 달성
}
export interface RaceDef {
  id: string;                      // 'R01'..'R12'
  sector: number;
  vehicle: 'foot' | 'jetpack' | 'hover' | 'ship' | 'warp' | 'glider';
  rings: [number, number, number][]; // 월드 좌표
  goldSec: number;
}
```

```ts
// core/save-schema.ts — 세이브 v6 추가 필드
export interface SaveV6 {
  ver: 6;
  // ...기존 v5 필드 유지...
  story: { beat: number; seen: Record<string, boolean> };       // STORY 7.1

  quests: {
    active: Record<string, { step: number; progress: number; startedAt: number }>;
    done: Record<string, number>;                // questId -> 완료 playSec
    failed: Record<string, number>;              // 시간제 실패 횟수
  };

  collectibles: {
    stars: Record<number, number>;               // sectorId -> 20비트 마스크(획득한 별)
    starsSpent: number;                          // 별지기에서 교환한 수
  };

  races: Record<string, { bestMs: number; medal: 0 | 1 | 2 | 3; vehicle: string }>;

  ach: {
    got: Record<string, number>;                 // 업적 id -> 달성 playSec
    counters: {                                  // 누적형 업적용 카운터
      stolenTotal: number;
      quizStreak: number; quizStreakBest: number;
      reviewCount: number;
      watcherLooks: number;                      // 시선 수호신 숨김 횟수
      disguiseSpotted: number;
      warpUses: number;
      wandererQuests: number;
      perfectDoors: number;
      noHitSector: Record<number, boolean>;      // 섹터별 무피격 유지 여부
      slowSteals: number;
    };
  };

  npc: {
    spoke: Record<string, boolean>;              // 첫 대화 연출 1회성
    wandererSector: number;                      // N14 현재 위치
    wandererDay: number;                         // 마지막 변경 일자(로컬 날짜 YYYYMMDD)
  };

  home?: { owned: ('tent' | 'cabin' | 'space' | 'castle')[]; sprout: boolean };
  playSec: number;                               // 기존
}
```

- **마이그레이션**: v5 → v6에서 `quests: {active:{},done:{},failed:{}}`, `collectibles.stars = {}`, `races = {}`, `ach = {got:{}, counters:{...0}}`로 초기화. 기존 `S.mi`(미션 진행)는 유지하고, 도감·`S.stolen`으로 일부 업적(A09, A17)을 **소급 달성**시킨다.
- 업적 달성 판정은 미션처럼 매 프레임이 아니라 **이벤트 훅**(훔침·퀴즈·획득 시)에서만 `checkAch()`를 부른다(성능).
- 세이브 용량: 별조각 마스크 12개 + 소량 카운터 → 1KB 미만 증가 예상.

ROADMAP 경고(시뮬레이터는 실측보다 6~10배 낙관)를 전제로, **시뮬 결과는 실측으로 보정한 뒤에만 신뢰**한다.

1. **하네스 확장**: `tests/e2e/` 아래에 `balance.spec.ts` 추가(500줄 이하). `fixtures.ts`의 `game` 픽스처와 `?debug=1` 훅을 사용해 세이브를 주입하고 가속 시계(`playSec` 점프)로 시간을 흘린다.
2. **시나리오 세이브 6종**: S1 시작 / S3 / S6 / S9 / S12 진입 직후 / 엔딩 직후를 JSON 세이브로 준비 → `page.addInitScript`로 `localStorage.stealPlanet4`에 주입(save.spec 방식).
3. **자동 플레이어 봇**: 가까운 행성 → 훔침 → 기지 → 암시장 판매 → 상점 구매 정책 + 의뢰 수락·완료 정책을 둔다. 구역별로 **소요 시간 vs 누적 시각 표(CONTENT_PLAN 2장)** 를 비교해 출력한다.
4. **실측 보정**: 사람이 한 구역을 직접 플레이한 시간과 봇 시간의 비율(보정 계수 k)을 구해 `pacing.ts`에 반영하고 M7 때 다시 비교한다.
5. **의뢰/업적 보상 점검**: 모든 의뢰를 수행한 봇과 건너뛴 봇의 최종 시각 차이가 **전체 시간의 10% 이내**인지(의뢰가 진행을 깨지 않게). 업적 금화 보상 합계가 해당 구역 평균 수익의 **5% 이내**인지.
6. **회귀**: 밸런스 변경 때마다 `npm run test:e2e` 전체 + balance.spec의 구역별 시간 오차 ±20% 확인. FPS 기준선도 병행(TESTING 4항).
7. **학습 데이터**: 퀴즈 정답률 목표 — 기초 80%·표준 60%·심화 40%. 정답률이 크게 벗어난 문항은 문제 은행에서 수정 대상으로 보고.
