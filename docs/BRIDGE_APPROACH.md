# 도시–현수교 연결부 수정 (2026-11-05)

사용자가 지적한 연결부는 도시 도로에서 다리까지 39u 안에 중심선을 74u 옮기는 짧은 S자였다. 도로 폭이 넓어지는 구간까지 겹쳐 안쪽 보도가 급하게 접혔다.

- 도시 직선 도로 z=272부터 램프 z=372까지 100u에 걸쳐 진입한다. x 방향은 5차 보간으로 이동해 양끝 접선·곡률을 직선에 맞췄다. 본 상판·주탑·다리 중심 x=74·야생지 도로는 유지했다.
- 도로 모델과 지형 평탄화는 같은 `data/bridge.ts`의 `cityApproach`를 사용한다.
- 차로 확폭에 맞춰 점선이 나타나고, 가장자리 흰 선과 보도는 상판 단면에 맞춘다.
- 기존 직선 도로의 남은 꼬리, 곡선과 겹친 컨테이너·야자수·가로등을 정리했다. 남쪽 거래의 선 개구는 실제 곡선 폭으로 계산한다.
- 새 진입 구간은 주차 자리 생성 대상에서 제외해 보행·주행을 막던 정차 차량을 없앴다.

검증: 타입 검사, 진입 곡선의 곡률/보도 여유 검사, 도시→야생지 보행, 세단 자율 추종 주행, 상판 밖 낙하·모델 예산 검사 총 5개 통과. 세단 충돌/침수 0회. 스크린샷은 `client/tests/out/bridge-approach-top.png`, `bridge-approach-oblique.png`.
