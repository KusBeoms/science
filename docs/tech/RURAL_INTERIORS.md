# 농촌·교외 주택 출입 (2026-11-06)

기존 도시 건물/랜드마크만 실내 목록에 있었기 때문에 외곽·농촌의 보이는 주택에는 들어갈 수 없었다. 실제 렌더 배치에 성공한 집만 실내 목록 뒤에 동적으로 등록한다. 기존 도시 `ENTERABLES` ID와 앞부분 index는 유지한다.

## 대상과 생성 방식

- 현재 수치 검수: 농촌 주택45채, 등산로 입구 나무 산장1동, 도시 교외90채, 합계136채. 농촌의 기존 COUNTRY 주변 주택은45채 안에 포함된다. 별도 `hut()` 모델 함수는 현재 호출되지 않으므로 중복 집으로 세지 않는다.
- 헛간·사일로·온실·풍차·정자와 교도소는 이번 주거 출입 등록 대상이 아니다. 기존 도시의 상점/랜드마크 기능은 유지한다.
- `data/rural-entries.ts`: accepted 주택의 모델·회전·바닥 높이·문·접근로 시작점 보관. 같은 ID 재등록은 기존 객체를 갱신해 중복을 만들지 않는다. 나무는 같은 문/경사로 여유를 비운다.
- `data/interiors.ts`: 기존 도시 목록을 먼저 구성하고 `CITY_ENTERABLE_COUNT` 이후에 `registerRuralInterior()`가 추가한다. 실물 좌표를 반영한 문 높이와 모델 정보를 함께 저장한다.
- `render/rural-village.ts`, `rural-entry.ts`: 실제 accepted 농촌 집의 회전 몸체 충돌, 문 앞 평탄판, 지면 연결 경사판과 같은 높이의 보행 데크를 만든다. 후보지만 있고 배치되지 않은 집은 등록하지 않는다.
- `render/wild-mountain.ts`: 나무 산장도 같은 경로로 등록한다. 산장 기초 코너의 최고 지면을 기준으로 바닥·기초·문·창문 조명을 함께 올려 기존 지형 관통을 없앴다.
- `render/city-fringe.ts`: accepted 교외 집90채의 기존 문/연결 데크를 재사용한다. 추가 접근 모델을 중복 생성하지 않는다.

실내 메시를 집마다 상시 만들지 않는다. 기존 `buildRoom()`을 진입 시 한 번 호출하고 월드 밖의 방 한 곳만 활성화한다. 나가면 그룹과 방 소유 지오메트리/벽 재질을 해제하고 공유 표면 재질은 유지한다.

## 문과 보행 계약

농촌의 모델 로컬 +z 정면, 문 위치, 회전 기초, 실제 몸체 충돌과 경사판이 같은 좌표 프레임을 쓴다. 회전한 집의 빈 bounding-box 모서리가 문 앞을 막지 않도록 몸체는 얇은 AABB 행으로 등록한다. 기초도 실제 벽 치수에0.5u를 더한 회전 박스로 맞춘다.

등록된 `door.y`는 보행판 상면과 같다. 진입 탐색은 수평 거리뿐 아니라 이 높이도 확인해 기초 아래에서 위층 문으로 들어가지 않게 한다. 접합부에는 실제0.1u 문턱판과 동일한 평탄 데크를 둔다. 공통 `core/deck.ts`에도1e-7u 오차 여유와 범위 내 높이 보간을 적용해, 회전한 교외 현관의 정확한 끝점에서 높이가 누락되지 않게 한다.

## 퇴장 후 이동 복구

`game/interior.ts`는 먼저 외부 충돌 층을 열어 저장된 문 높이에서 안전 위치를 찾는다. `core/exit-position.ts`는 몸 반지름0.5u의 여유와 짧은 연속 보행 경로를 함께 검사한다. 문이 주차 차량에 막혔다면 가까운 같은 높이의 이동 가능한 위치로 나온다. 정상 퇴장에서는 눌린 이동 키나 정당한 모달/퀴즈 상태를 무조건 초기화하지 않는다.

주변 전체가 막혔으면 방과 충돌 상태를 보존한 채 퇴장을 거절한다. 방 그룹을 먼저 파괴하거나 플레이어를 차/벽 속에 두지 않는다. 택시 등 즉시 다른 곳으로 이동시키는 호출자만 `leaveBuilding(true)` 강제 정리를 사용한다.

## 검증

소스 TypeScript를 Node에서 메모리로 읽어 렌더 배치와 높이·충돌을 검사했다(배포JS emit 없음).

- 136개 문 등록, 농촌45주택/산장1/교외90.
- 각 접근로40단계 보행·충돌 검사 실패0.
- 136개 문 모두 안전 퇴장점 검사 통과, 주차 장애물 주변 대체 출구 확인, 완전 차단 시 null 확인.
- 회전 주택/산장 기초 코너의 지면 관통0.
- `npx tsc --noEmit --project client` 통과.

`tests/e2e/rural-interiors.spec.ts`는 실제 브라우저에서 다음을 검사하도록 작성했다. 브라우저 실행과 최종 결과 집계는 루트 담당이다.

1. 모든 렌더 주택의 동적 등록·도시 index 보존·접근로/문 높이.
2. 모든 등록 집의 진입 프롬프트·방1개 지연 생성·퇴장 높이·방 지오메트리 해제.
3. 문 앞 주차 차량이 있을 때 안전한 퇴장과 이후 이동, 완전 차단 때 방 보존 및 장애물 제거 후 재시도.

최종 브라우저에서 위3개를 모두 통과했다. 문 높이 누락을 보정한 뒤 전체 실내·교외·경관·차량 파손·포탈·고가도로·컷신도 관련 회귀로 확인했다. 사진은 `tests/out/rural-lodge-entry.png`, `rural-house-interior.png`에 생성하며, 실내/방 소유 지오메트리 해제까지136곳을 실제로 검사했다.

## 교외 데크 공통 정밀도 보정

루트의 브라우저 검사에서 교외 현관 약27곳이 보행 자체는 가능해도 정확한문 좌표에서0.12u 현관 높이를 잃는 것을 발견했다. 회전한 데크 끝점의 축 투영이 길이보다 미세하게 커져 엄격한경계 검사에 누락된 원인이었다.

`core/deck.ts`는 bbox·선분 길이·반폭 검사에1e-7u 수치 오차여유를 두고 높이는0~길이로clamp한 t로 보간한다. 실질적인 보행 폭 확장은1e-7u에 그치며 별도90개 기초판을 추가하지 않았다. 최종 source Node 검사에서136개문의 실제 groundH 높이와door.y 차이는최대4.44e-16u, 등록데크468개끝점표본의누락은0이다. noEmit 검사 통과. 실제다리/입체교차로와최종브라우저회귀는root가실행한다.
