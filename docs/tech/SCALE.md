# 실제 축척 계약 (SCALE)

도심 재설계(`design/CITY_REDESIGN_PLAN.md` 12-1 / 13절)의 **축척 기준**. 외관·실내·사람·차량·도로는 모두 이 표의 목표값에서 생성한다. 이 문서는 값만 정하며 코드는 바꾸지 않는다. 현행 값과 어긋나는 곳은 3절에 모았다.

- **1u = 1m**. y는 위쪽, 바닥 기준 `floorY`(건물 대지 높이 = `groundH`).
- 각도는 도(°), 거리·폭·높이는 m(=u), 속도는 u/s.
- 단일 출처: 스키마 상수는 `client/src/data/city-schema.ts`(`SCALE`, `ROAD_CLASS_DEFAULTS`)에 같은 수치로 둔다. 이 문서와 어긋나면 이 문서를 먼저 고치고 상수를 맞춘다.

## 1. 현행 코드에서 확인한 값

| 항목 | 현행 값 | 위치 |
|---|---|---|
| 플레이어 모델 | 블록 캐릭터 원본 높이 약 6.2u(발~머리 위) × `PLAYER_SCALE` 0.38 = **약 2.3u** | `render/characters.ts` `blocky()`, `core/scale.ts` |
| 눈높이(카메라 주시점) | `EYE_Y = 1.8` | `core/scale.ts` |
| 속도 | 걷기 약 9, 뛰기 약 15 u/s (`MOVE_MUL` 0.78) | `data/cars.ts` 머리 주석 |
| 건물 층고 | 일반 5.2u, 상점 5.6u (`floorH`) | `render/city/building.ts:24`, `data/city-w7.ts:96` |
| 실내 벽 높이 | `wallH = 5 + 2(층수-1)`, 고층 11, 랜드마크 7, 집 5(산장 8) | `data/interiors.ts` |
| 실내 방 크기 | `w` 9~30, `d` 9~26 (농가·집 `w` 9~24, `d` 9~22) | `data/interiors.ts` |
| 문 | 건물 정면 중앙, 발자국 바깥 1u 지점이 문 좌표(`doorOf`). 개구 폭·높이 개념 없음 | `data/city.ts` `doorOf` |
| 도로 | 대로 24u(보도 3), 항구길 16, 보행로 10, 골목 6~8(보도 1~2), 구역 도로 10(보도 3) | `data/city.ts` `CITY_ROADS` |
| 다리 | 반폭 `HW` 23.5, 도로 반폭 14, 상판 높이 `DECK_Y` 5.5 | `data/bridge.ts` |
| 차량(예) | 세단 5.0×2.2×2.0, 해치 4.2×2.1×2.0, 버스 9×2.7×3.6, 밴 5.6×2.4×3.1 (길이×폭×높이) | `data/cars.ts` |

해석: 플레이어는 약 2.3u인데 층고는 5.2u라서 **층고/키 = 2.3배**(현실 약 1.7배), 차 폭 2.2u는 사람 몸 폭(약 0.9u)의 2.4배(현실 약 3.7배)다. 즉 사람이 건물·차에 비해 크고, 도로는 사람 기준 상대적으로 좁다.

### 2-4. 도로 단면 (5개 등급)

모든 폭은 m. 좌우 대칭이 기본이며, 코드의 `ROAD_CLASS_DEFAULTS`와 같은 수치다. 차로 수는 **한쪽 방향** 기준이다(일방통행이면 한쪽 방향만 존재).

| 등급 | 코드 | 차로 수(편도) | 차로 폭 | 중앙분리대 | 주차대(한쪽) | 보도(한쪽) | 식재대(한쪽) | 갓길(한쪽) | 총 폭 | 최대 경사 | 비고 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 고속(간선 자동차전용) | `expressway` | 3 | 3.5 | 3.0 | 0 | 0 | 0 | 2.5 | **29.0** | **6%** | 보행 금지, 입체(교량/터널) 위주 |
| 주간선 | `arterial1` | 3 | 3.25 | 2.0 | 0 | 3.5 | 2.0 | 0 | **32.5** | **8%** | 신호교차로, 버스 가능 |
| 보조간선 | `arterial2` | 2 | 3.25 | 0.6 (이중 중앙선) | 0 | 3.0 | 1.5 | 0 | **22.6** | **8%** | 주차대 2.3은 구간 덮어쓰기 가능 |
| 집산도로 | `collector` | 1 | 3.0 | 0 | 2.3 | 2.5 | 1.2 | 0 | **18.0** | **8%** | 양쪽 주차 가능 |
| 국지도로 | `local` | 1(공용 2.75×2) | 2.75 | 0 | 2.0 (한쪽 기본) | 2.0 | 1.0 | 0 | **13.5** | **10%** | 주택가, 보차 혼용 가능 |

총 폭 산식: `2 x (편도 차로 수 x 차로 폭) + 중앙분리대 + 주차대(좌+우) + 2 x (보도 + 식재대 + 갓길)`. `local`은 주차대가 한쪽(2.0)뿐: 5.5 + 2.0 + 2 x (2.0 + 1.0) = 13.5.

기타 도로 규칙(목표): 연석 높이 0.15, 횡단보도 폭 3.0, 정지선 후퇴 1.5, 교차로 모서리 반경 국지 6 / 집산 8 / 간선 12, 보도 유효 통행 폭 최소 1.5, 가로등 높이 6~9, 가로수 식재대 최소 1.0.

## 3. 현행 값 중 목표와 어긋나는 것 (코드는 아직 바꾸지 않음)

| 항목 | 현행 | 목표 | 격차 / 영향 |
|---|---|---|---|
| 플레이어 키 | 약 2.3 | 1.75 | `PLAYER_SCALE` 0.38 → 약 0.29. 카메라 거리·속도·점프·충돌 반경 연동 |
| 눈높이 | 1.8 | 1.65 | `EYE_Y` |
| 걷기/뛰기 | 9 / 15 | 1.4 / 4.0(실제) | 게임 속도는 열린 질문 |
| 층고 | 5.2 / 5.6 | 3.0 / 4.2 | `floorH`, `FLOOR_H`(city-w7). 실내 `wallH` 공식 전체 교체 |
| 실내 방 최소 | 9×9 | 건물 발자국에서 역산 | `Math.max(9, …)` 클램프 제거, 가구 재배치 필요 |
| 문 | 개구 개념 없음, 문 좌표만 | 1.0×2.1 + 로컬 위치 | 스키마 `interior.door`로 신설 |
| 차량 | 세단 5.0×2.2×2.0 등 대체로 더 크고 높음 | 2-3절 표 | 길이 +5~10%, 폭 +10~20%, 높이 +30~40% 과대. 버스 9 → 11로 더 짧음 |
| 도로 폭 | 대로 24 / 구역 10 / 골목 6~8 | 29~32.5 / 13.5~18 | 사람이 작아지면 상대 폭은 자연스럽게 넓어짐. 기존 값은 새 지도에서 폐기 |
| 보도 | 1~3 | 2.0~3.5 | |
| 다리 상판 반폭 | 23.5 | 고정 앵커(다리 끝) 그대로 유지 | 13-1절: 다리 끝은 위치·폭·높이 고정, 새 도로는 이에 맞춤 |
| 최대 경사 | 규정 없음 | 6 / 8 / 8 / 8 / 10% | 13-3절 |

플레이어 키를 줄이는 대신 건물을 줄이는 방식(층고만 3.0으로)은 같은 비율이므로 둘 중 하나를 택한다. 계약은 **사람을 1.75로 두고 건물·차를 현실 값으로 맞추는 것**을 기본으로 하며, 기존 모델 코드(캐릭터 `blocky()`)는 높이를 1.75에 맞게 정규화하는 래퍼가 필요하다. 이 선택은 P2 이후 결정으로 W8_CONTRACT.md의 열린 질문에 남긴다.

## 4. 스키마 상수와의 대응

`city-schema.ts`의 `SCALE`(사람·층·문·계단·차량·주차칸), `ROAD_CLASS_DEFAULTS`(2-4절 표), `LIMITS`(개수 상한), `RANGES`(값 범위)가 위 수치의 코드 표현이다. 검증기(`city-validate.ts`)는 범위를 벗어난 건물/도로 값을 `range` 오류로 보고한다.
