## 0. 현재 코드 기준선 (조사 결과)

| 항목 | 현재 | 이 문서가 바꾸는 점 |
|---|---|---|
| `hud.ts` `toast(m)` | 문장을 `#toast`에 출력 | 스토리/튜토리얼 경로에서는 **호출 금지**. `iconToast(icons[])` 신설(확정, 9장 #1). 시스템 오류(저장 실패 등)만 문장 `toast` 허용 |
| `hud.ts` `infoHTML` | 행성 이름·수치·`fact` 문장 | 도감·상점 맥락 외 비노출. 월드 상 정보 줄은 아이콘+숫자 위주로 축약 |
| `hud.ts` `addHudLine` | `#lines`에 문자열 줄 | 아이콘 줄(이모지+SVG 게이지)로 사용 가능. 문장 줄 금지 |
| `modal.ts` `openModal` | 오버레이 열면 `paused()` | 컷신은 모달이 아닌 **별도 레이어**(`#cine`, z-index 8). 일시정지는 `paused()`에 `G.cine` 추가 |
| CSS 토큰 | `--bg --fg --dim --line --card --acc`(청색 단일 강조) | 의미색 토큰 `--ok --warn --danger --gold` 추가 제안(8.2) |
| z-index | HUD 2, 오버레이 5, `#flash`류 9 | 컷신 8(오버레이 위, flash 아래). 레터박스는 컷신 내부 |
| 모바일 | `body.touch`, 조이스틱 좌하, 점프/달리기 우하, 상단 `#btns` 우상 | HUD 배치 4장은 이 점유 영역을 피한다 |
| 캐릭터 | `blocky()` 블록형 + `face` 5종(0~4) | 감정은 **머리 위 말풍선**이 담당(얼굴 표정 변경 불필요) |

## 2. 컷신 디렉터 데이터 포맷 (TS 초안)

STORY 7.1을 확장. **텍스트 필드 없음**(`bubble.text` 같은 필드는 타입에 존재하지 않는다). 파일: `game/cutscene.ts`(런타임), `data/cutscenes.ts`(데이터).

```ts
export type CutId = 'c01_love' | 'c02_gauge' | 'c03_caught' | 'c04_hide'
  | 'c05_triple' | 'c06_chase' | 'c07_safe' | 'c08_rich' | 'c09_go'
  | 'c10_request' | 'c11_knife' | 'c12_free';

export type Ease = 'linear' | 'in' | 'out' | 'inOut' | 'back';

/** 감정/사물 아이콘 키 (3장 사전의 key). 문자열 리터럴 유니온으로 오타를 컴파일 때 잡는다 */
export type IconKey = keyof typeof ICONS;

export interface CutDef {
  id: CutId;
  beat: number;                 // STORY 비트 번호 (1~12)
  durSec: number;               // 5~25
  skippable: true;
  skipHold?: number;            // 길게 누르기 확인(초). C11만 1.0
```

핵심 규칙
1. **시간 기준은 `G.gameT`가 아닌 컷신 전용 `cineT`**(일시정지·탭 이탈 시 정지). 키 사이는 `ease` 보간, `cut:true`는 보간 없이 점프.
2. `play(id)` → `G.cine = {def, t:0}`; `paused()`는 `G.cine && def.lockInput !== false`일 때 true. 월드 시뮬은 멈추고 렌더·사운드·말풍선만 돈다.
3. `skip()`은 (a) `endState` 적용, (b) 모든 `onEnd` 실행, (c) 0.3초 페이드. **게임 상태 변경은 `onEnd`에만** 둔다(재생 중 변경 금지) → 건너뛰기와 정상 종료의 결과가 동일.
4. 세이브: `S.story = {beat, seen: Record<CutId, 0|1>, ended?: 0|1}`; `seen`이 0이면 건너뛰기 버튼을 2초 지연 표시, 1이면 즉시.
5. 말풍선은 DOM(`#cine .bub`) — 월드 위치 투영, 최대 동시 3개, 아이콘은 이모지+`data-shape` 속성(3.3)으로 외곽선 도형 병기.

## 3. 이모지/아이콘 사전
### 3.1 설계 규칙
- **한 말풍선 = 이모지 1~3개**, 3개 초과 금지. 모든 의미는 **이모지 + 외곽 모양 + (선택)소리**의 3중 병기.
- 이모지 렌더링은 OS마다 다르므로 `ICONS[key] = {emoji, shape, svg?}`로 추상화. 1차는 이모지, 2차(품질 단계)에 핵심 12개(💗💰❗⚠️👁️🍎🗡️😢🎒🏠⏭✅)만 자체 SVG 스프라이트로 교체(확정, 9장 #3). `svg`가 있으면 우선, 나머지는 이모지 유지.
- 말풍선 외곽 모양 `shape`(색이 아닌 **형태**로 의미 구분): 
  - `round` 둥근 구름 = 감정/생각, `spike` 톱니 = 위험/경고, `square` 각진 사각 = 의뢰/지시, `hex` 육각 = 상태/시스템.

### 3.3 모양 병행 접근성 구현
- DOM: `<span class="ic ic-spike" data-shape="spike" role="img" aria-label="{lang.key}">⚠️</span>` — `aria-label`은 **스크린리더 전용**이고 시각 텍스트가 아니므로 무문자 규칙에 위배되지 않는다(확정: 허용, 단 **한 단어**로 제한 — 9장 #4).

## 5. 튜토리얼 (무문자)
### 5.1 방식
- **상황 트리거 힌트**: 처음 해당 상황이 되면 1회, 대상 근처에 **손가락/키 아이콘 + 대상 하이라이트**를 띄운다. 행동 성공 시 ✅ 팝 후 사라짐. `S.story.hints[key]=1`로 영구 비표시. 성공 전에는 10초 후 재표시(최대 3회).
- 힌트는 **전부 `HintDef` 데이터**: `{key, when(state), anchor(target), icons[], loop: 'tap'|'drag'|'hold'|'pulse'}`. 문자열 필드 없음.
- 키 아이콘은 입력 장치에 따라 교체(데스크톱: ⌨️ 키캡 모양 `W A S D`/`E`/`F`/`Shift`/`Space`는 **글자 키캡 허용**—기기 표면 표기이므로 문장이 아님. 터치: 손가락 👆 + 조이스틱 궤적).
### 5.2 힌트 목록 (상황별)
| key | 트리거 | 표시 | 성공 조건 |
|---|---|---|---|

| quiz | 퀴즈 첫 오픈 | 보기 4개 중 하나를 👆가 가리킴(첫 1회만, 정답 비누설) → **문장 없음**, 타이머 모양 ⏳만 | 보기 선택 |

- 한 번에 힌트 1개만. 우선순위: 생존(`caught`/`watch`) > 진행 > 편의.

## 8. 수용 기준 (Done 조건)
### 8.1 기능
1. 비트 1~12 각각에 대응하는 컷신 12개가 `data/cutscenes.ts`에 존재하고 STORY 비트 번호로 조회된다(`beat` 필드).
2. 컷신 데이터에 **문자열 필드가 없다**(`bubble.text` 부재). 린트 규칙: `data/cutscenes.ts`에서 한글 문자열 리터럴 0건.
3. 모든 컷신은 길이 5~25초, 건너뛰기 가능(C11은 최초 시청에 한해 1초 길게 누르기, 재시청은 즉시). 건너뛰어도 `onEnd` 결과(비트·플래그·게이지·저장)는 정상 종료와 동일.
4. 컷신 중 `paused()`가 true(lockInput 컷신), 종료 시 입력·카메라 복귀, 일시정지 후 재개 시 타임라인 정확히 이어짐.
5. 신규 세이브(`S.story`) 마이그레이션 후 기존 세이브가 깨지지 않는다(`save-schema` 단위 테스트).
6. 사과 게이지·경계 👁️·가방 개수 등 스토리 HUD에 **문장이 없다**(DOM 텍스트 노드 검사 E2E).
7. 튜토리얼 힌트 13종이 각 트리거에서 1회 표시, 성공 시 소멸, 재표시 규칙 동작(E2E).
8. 컷신 총 시청 시간 최초 ~2.6분 ± 20%.
9. `iconToast`가 존재하고 스토리·튜토리얼 경로에서 `toast()` 호출이 0건(저장 실패 등 시스템 오류 제외, grep/린트 검사).
10. 사과 게이지 목표 = 사과 행성 가격으로 설계되어 C08 종료 시 정확히 100%(단위 테스트).
11. `aria-label`은 한 단어만 사용하고 시각 텍스트로 노출되지 않는다. 컷신 재시청 메뉴(🎞️)는 `S.story.ended` 이후에만 노출.
12. 첫 실행 시 OS 모션 감소 설정이 인게임 토글에 자동 반영된다.
### 8.2 품질 검증 방법
- E2E(Playwright, `?debug=1`): `__game.cine.play('c11_knife')`, 시간 가속 후 `S.story.ended === true` 확인, 건너뛰기 경로도 동일.
- 스냅샷: 컷신별 대표 프레임(데스크톱 1280×720, 모바일 390×844) 2종씩.
- 수동: 색약 시뮬 / 모션 감소 / 소리 끔 3 시나리오로 비트 3·6·11을 통과시켜 정보 손실이 없는지 확인.
- 성능: 컷신 중 평균 프레임 ≥ 30fps(모바일 중급 기기), 말풍선 투영 계산 프레임당 < 0.5ms.
- 파일 규칙: 신규 `src/**/*.ts`·`style/*.css` 500줄 이하(CLIENT.md 규칙) → `data/cutscenes-a/b.ts`로 분할 가능.
