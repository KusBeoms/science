# PX Grass Lawn 04 — 흙과 마른 풀이 드러난 넓은 잎 잔디

## 눈으로 확인한 스타일

`PX_Grass_Lawn_04_albedo.jpg`의 전체와 중앙 확대를 직접 확인했다. 초록색의 비교적 넓은 잎 사이에 갈색 흙과 마른 잎/풀 찌꺼기가 드러나며, 잔디 밀도가 고르지 않다. 이름에 Lawn이 있지만 촘촘하고 균일한 경기장 잔디보다는 밟힌 교외 잔디·자연 초지에 가깝다. 별도 구체/preview 이미지는 없다.

## 반복·크기와 권장 위치

타일형 PBR 잔디 후보지만 2×2 이음새의 무봉제성은 별도 검증하지 않았다. 원본 물리 면적은 확인되지 않았다. 한 타일2~4u로 시작하고 넓은 잎을 플레이어 발과 비교해 조정한다. 이것은 게임용 제안이며 실물 촬영 크기가 아니다. 갈색 빈터가 반복되어 보이면 저주파 잔디색/마스크와 섞는다.

권장 위치: 교외 단독주택 정원, 농촌 목장 바깥, 작은 호수 마을과 숲 사이의 밟힌 초지. Grass005의 밝고 고른 도시 공원 잔디와 구별해 생활권/자연 경계에 사용한다.

## 게임에서 가볍게 쓰는 방법

- 원본 보관용 폴더다. 브라우저 배포에는 별도 512~1024px 색상 파생본부터 사용하고, 근접 검사에서 필요할 때만 2048px로 올린다. 원본 해상도 전체를 지형 청크마다 복제하지 않는다.
- 색상은 sRGB, normal/roughness/AO/height 같은 수치 맵은 선형 데이터로 취급한다. 색상 1장부터 공유 재질에 연결하고, 현재 재질이 해당 슬롯을 지원할 때만 normal·roughness를 추가한다. 모든 맵의 UV 반복·회전·원점을 같이 맞춘다.
- 밉맵과 반복 샘플링을 사용하고 먼 거리에서는 기존 정점색/LOD와 자연스럽게 섞는다. JPEG 파일 크기가 작아도 GPU 메모리가 작다는 뜻은 아니다. RGBA8 기준 4K 한 장은 약64MiB, 밉맵 포함 약85MiB이고 8K는 약256/341MiB다. 1024px는 약4/5.3MiB다.
- displacement는 기본 런타임에서 끈다. 화면용 높이 맵으로 지면만 바꾸어 native2.5u 지형·보행·호수/도로의 높이 계약이 어긋나게 하지 않는다. 노멀은 시각 요철이며 보행 높이를 바꾸지 않는다.
- 미리보기의 구체 조명/그림자를 게임 색상으로 사용하지 않는다. 실제 연결 상태와 배포 파생본은 [텍스처 전체 안내](../../README.md)에서 관리한다.

## 출처·라이선스 상태

`PX_` 접두사만으로 공급사를 확인할 수 없으며, 폴더에는 출처 URL·원문 라이선스·구매 내역이 없다. **공급사 미확인, 라이선스 미확인**으로 기록한다. 이름이 비슷한 다른 제공자의 이용 조건을 적용하지 않는다. 웹 조회는 하지 않았다.
