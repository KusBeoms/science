# Poliigon Grass Patchy Ground 4585 — 얼룩진 황록색 초지

## 눈으로 확인한 스타일

BaseColor 전체/중앙 확대와 Preview1 구체를 직접 확인했다. 짧고 가는 초록 잔풀에 황록색 마른 풀·갈색 흙의 불규칙한 얼룩이 섞여 있다. 전체는 녹황색의 생활 초지이며, Grass005보다 얼룩과 밀도 변화가 크다. 미리보기의 밝은 면과 그림자는 구체 조명 효과이므로 BaseColor와 구분한다.

![구체 미리보기](<Poliigon_GrassPatchyGround_4585_Preview1.png>)

## 원본 구성

README 제외 원본 파일7개와 macOS 관리 파일 `.DS_Store`1개(합계8개)다. 루트의 `Poliigon_GrassPatchyGround_4585_Preview1.png`는 **2048×2048 RGBA PNG** 미리보기1개이며 게임 타일 맵으로 사용하지 않는다. [8K/README.md](8K/README.md)에 실제 맵5개와 MaterialX1개의 상세 역할을 기록했다.

**Normal 파일은 없다.** MaterialX는 `Poliigon_GrassPatchyGround_4585_Normal.png`를 참조하지만 실제 디스크에 없는 누락 참조다. 원본 재질의 자동 임포트 성공을 가정하지 말고 색상 단독 또는 노멀 없는 재질 경로를 사용한다.

## 반복·크기와 권장 위치

MaterialX가 `tiledimage`와 UV 반복 입력을 제공하므로 반복형 지면 재질 후보로 볼 수 있으나 2×2 이음새는 별도 검사하지 않았다. 실제 면적/미터 단위는 확인되지 않았다. 한 타일3~6u를 시작값으로 권장한다. 이는 게임 월드 스케일 제안이며 원본 물리 크기가 아니다.

농촌 목장 밖 초지, 호수 마을 외곽, 공원 중 덜 관리된 구역, 도시와 산림 사이 녹지에 권장한다. 얼룩이 큰 규칙으로 보이지 않게 월드 좌표 UV와 완만한 색 마스크를 함께 사용한다.

## 게임에서 가볍게 쓰는 방법

- 원본 보관용 폴더다. 브라우저 배포에는 별도 512~1024px 색상 파생본부터 사용하고, 근접 검사에서 필요할 때만 2048px로 올린다. 원본 해상도 전체를 지형 청크마다 복제하지 않는다.
- 색상은 sRGB, normal/roughness/AO/height 같은 수치 맵은 선형 데이터로 취급한다. 색상 1장부터 공유 재질에 연결하고, 현재 재질이 해당 슬롯을 지원할 때만 normal·roughness를 추가한다. 모든 맵의 UV 반복·회전·원점을 같이 맞춘다.
- 밉맵과 반복 샘플링을 사용하고 먼 거리에서는 기존 정점색/LOD와 자연스럽게 섞는다. JPEG 파일 크기가 작아도 GPU 메모리가 작다는 뜻은 아니다. RGBA8 기준 4K 한 장은 약64MiB, 밉맵 포함 약85MiB이고 8K는 약256/341MiB다. 1024px는 약4/5.3MiB다.
- displacement는 기본 런타임에서 끈다. 화면용 높이 맵으로 지면만 바꾸어 native2.5u 지형·보행·호수/도로의 높이 계약이 어긋나게 하지 않는다. 노멀은 시각 요철이며 보행 높이를 바꾸지 않는다.
- 미리보기의 구체 조명/그림자를 게임 색상으로 사용하지 않는다. 실제 연결 상태와 배포 파생본은 [텍스처 전체 안내](../../README.md)에서 관리한다.
