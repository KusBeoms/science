# Ground110 — 회색 쇄석·흙·나뭇가지가 섞인 거친 지면

## 눈으로 확인한 스타일

Color 전체와 중앙 확대, 구체 미리보기를 직접 확인했다. 밝고 어두운 회색 각진 돌, 회갈색 흙 빈틈, 가는 나뭇가지·마른 잎 조각이 뒤섞여 있다. 큰 돌과 맨흙 얼룩의 대비가 강하며 Ground103/104보다 표면 입자가 크고 숲 바닥·자갈길에 가까운 인상이다.

## 반복·크기와 권장 위치

타일형 PBR 재질로 쓰도록 구성되어 있으나 이 문서에서는 2×2 연결 경계나 회전 반복의 무봉제성을 별도 검증하지 않았다. 실물 촬영 면적/미터 단위는 확인되지 않았다. 아래 u는 현재 게임 월드 단위이며 원본의 물리적 크기를 뜻하지 않는다. MaterialX의 displacement scale1은 실제1m 높이라는 보증이 아니다.

한 타일2~4u를 시작값으로 권장한다. 큰 돌과 나뭇가지 무늬가 반복되므로 대면적 단독 사용보다 흙/잔디 사이 국소 패치로 사용한다. 실제 돌 모델과 비교해 바닥 무늬가 과대해지지 않게 한다.

권장 위치: 농촌 산길의 자갈 구간, 능선 아래 돌 많은 숲 바닥, 개울 접근부·호숫가의 육지 쪽. 부드러운 공원 잔디나 농작물 밭 전체에 사용하지 않는다.

## 게임에서 가볍게 쓰는 방법

- 원본 보관용 폴더다. 브라우저 배포에는 별도 512~1024px 색상 파생본부터 사용하고, 근접 검사에서 필요할 때만 2048px로 올린다. 원본 해상도 전체를 지형 청크마다 복제하지 않는다.
- 색상은 sRGB, normal/roughness/AO/height 같은 수치 맵은 선형 데이터로 취급한다. 색상 1장부터 공유 재질에 연결하고, 현재 재질이 해당 슬롯을 지원할 때만 normal·roughness를 추가한다. 모든 맵의 UV 반복·회전·원점을 같이 맞춘다.
- 밉맵과 반복 샘플링을 사용하고 먼 거리에서는 기존 정점색/LOD와 자연스럽게 섞는다. JPEG 파일 크기가 작아도 GPU 메모리가 작다는 뜻은 아니다. RGBA8 기준 4K 한 장은 약64MiB, 밉맵 포함 약85MiB이고 8K는 약256/341MiB다. 1024px는 약4/5.3MiB다.
- displacement는 기본 런타임에서 끈다. 화면용 높이 맵으로 지면만 바꾸어 native2.5u 지형·보행·호수/도로의 높이 계약이 어긋나게 하지 않는다. 노멀은 시각 요철이며 보행 높이를 바꾸지 않는다.
- 미리보기의 구체 조명/그림자를 게임 색상으로 사용하지 않는다. 실제 연결 상태와 배포 파생본은 [텍스처 전체 안내](../../README.md)에서 관리한다.

## 출처·라이선스 상태

`Ground110` 명명 및 `.tres`의 `acg_` UID를 근거로 **ambientCG 계열 배포본으로 추정**한다. 이 폴더에는 공급사 원문 페이지·다운로드 영수증·LICENSE/COPYING가 없어 출처 확정 및 라이선스 원문 확인은 하지 못했다. 알려진 다른 배포본의 조건을 이 파일에 자동 적용하거나 CC0로 단정하지 않는다. 웹 조회는 수행하지 않았다. 원본을 수정·재배포한 안내가 아니라 로컬 보유 파일의 분석 문서다.


## 현재 런타임 반영

이번 경량 런타임 팩에는 포함하지 않았다. 이 문서의 위치/맵 사용법은 후속 적용 권장안이며, 현재 게임 적용 사실과 구분한다.
