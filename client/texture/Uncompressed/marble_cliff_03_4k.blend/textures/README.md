# marble_cliff_03 — 실제 4K 맵

상위 [재질 안내](../README.md)의 배치/스케일 기준을 공유한다. diff 전체와 중앙 확대를 직접 확인했다. 회베이지/황갈색의 넓은 암반 덩어리에 녹슨 듯한 주황빛 세로 얼룩과 짙은 수평·대각 균열이 지나간다. 이름에 marble이 있지만 매끈한 실내 대리석 타일이 아니라 거친 야외 절벽 표면이다. 별도 구체/preview 이미지는 없다.

## 원본 구성

README 제외 이미지 **4개**, 모두 **4096×4096**이다.

| 파일 | 형식·정밀도 | 역할 |
|---|---|---|
| `marble_cliff_03_diff_4k.jpg` | JPEG8비트 RGB | sRGB 확산/기본색. 게임 색상 맵 후보. |
| `marble_cliff_03_nor_gl_4k.exr` | EXR · RGB float16 | OpenGL 계열 탄젠트 노멀. 선형 데이터로 취급한다. |
| `marble_cliff_03_rough_4k.exr` | EXR · Y float16 | 선형 거칠기. 밝을수록 거칠다. |
| `marble_cliff_03_disp_4k.png` | PNG16비트 단일 성분 | 상대 높이. 중간값/물리 높이 단위는 확인되지 않았다. |

별도 AO/metallic/opacity 맵은 없다. 추가 파일이 있다고 가정하거나 없는 경로를 요청하지 않는다. 노멀 EXR은 RGB float16이다. 색상 이미지에 이미 있는 균열 대비를 고려해 normal 강도를 작게 시작한다. 반복 회전으로 수평 층리 방향이 뒤집히지 않게 한다.

## 반복·게임 용도·성능

한 타일6~12u를 시작값으로 권장한다. 원본 이미지의 큰 수평 균열이 벽을 따라 가로 방향으로 남도록 세로면 UV를 배치한다. 모든 면을 잔디처럼 XZ 투영하면 층리가 눕거나 옆으로 늘어나므로 벽면 투영/삼면 투영을 검토한다. 원본 면적은 미확인이고 타일 무봉제성은 별도 검사하지 않았다.

도시 둘레 산의 노출 암벽, 동쪽 천문대 반도 절벽, 농촌 능선 바위·해안 바위의 세로면. 광장 바닥/실내 석재 포장보다 큰 자연 암반에 적합하다.

런타임은 diff512~1024px 파생본부터 시작한다. 노멀을 쓸 때만 EXR을 웹 재질용 선형 데이터 파생본으로 변환하고 축/색공간을 확인한다. JPEG/PNG의 밝은 색상 변환을 노멀 값에 적용하지 않는다. 원본 EXR과16비트 displacement는 기본 브라우저 이미지로 직접 연결하지 않는다. displacement는 기본적으로 끄며 보행 지형을 별도로 변형하지 않는다. RGBA8 4K한 장은 약64MiB, 밉맵 포함 약85MiB이므로 색상·노멀·거칠기를 전부 원본 크기로 올리지 않는다.

## 출처·라이선스 상태

파일명과 `diff/nor_gl/rough/disp_4k` 패키지 구성이 **Poly Haven 계열 배포본으로 추정**되지만 공급사 URL·제작자 정보·라이선스 원문은 폴더에 없다. 공급사 및 CC0 등 이용 조건은 원문 확인 전까지 확정하지 않는다. 웹 조회는 하지 않았다.
