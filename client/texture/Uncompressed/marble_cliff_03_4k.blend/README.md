# marble_cliff_03 — 황갈색·회색의 큰 절리 암벽

## 눈으로 확인한 스타일

diff 전체와 중앙 확대를 직접 확인했다. 회베이지/황갈색의 넓은 암반 덩어리에 녹슨 듯한 주황빛 세로 얼룩과 짙은 수평·대각 균열이 지나간다. 이름에 marble이 있지만 매끈한 실내 대리석 타일이 아니라 거친 야외 절벽 표면이다. 별도 구체/preview 이미지는 없다.

## 원본 구성

README 제외 **5개**: `marble_cliff_03_4k.blend`1개와 `textures/`의 이미지4개다. 파일 이름에 `.blend`가 붙은 이 경로는 디렉터리이며, 그 안에 같은 이름의 실제 Blender 파일이 있다. 이미지4개는 모두4096×4096이다. 상세 맵 역할/정밀도는 [textures/README.md](textures/README.md)에 기록했다. Blender 묶음 자체는 게임에서 직접 로드하는 재질 파일이 아니다.

## 반복·크기와 권장 위치

반복형 PBR 표면 후보이며 2×2 연결 경계는 별도 검증하지 않았다. 실제 촬영/스캔 면적은 미확인이다. 아래 u는 게임 시작 스케일이며 미터 단위의 원본 크기를 보증하지 않는다.

한 타일6~12u를 시작값으로 권장한다. 원본 이미지의 큰 수평 균열이 벽을 따라 가로 방향으로 남도록 세로면 UV를 배치한다. 모든 면을 잔디처럼 XZ 투영하면 층리가 눕거나 옆으로 늘어나므로 벽면 투영/삼면 투영을 검토한다.

권장 위치: 도시 둘레 산의 노출 암벽, 동쪽 천문대 반도 절벽, 농촌 능선 바위·해안 바위의 세로면. 광장 바닥/실내 석재 포장보다 큰 자연 암반에 적합하다.

노멀 EXR은 RGB float16이다. 색상 이미지에 이미 있는 균열 대비를 고려해 normal 강도를 작게 시작한다. 반복 회전으로 수평 층리 방향이 뒤집히지 않게 한다.

## 게임에서 가볍게 쓰는 방법

- 원본 보관용 폴더다. 브라우저 배포에는 별도 512~1024px 색상 파생본부터 사용하고, 근접 검사에서 필요할 때만 2048px로 올린다. 원본 해상도 전체를 지형 청크마다 복제하지 않는다.
- 색상은 sRGB, normal/roughness/AO/height 같은 수치 맵은 선형 데이터로 취급한다. 색상 1장부터 공유 재질에 연결하고, 현재 재질이 해당 슬롯을 지원할 때만 normal·roughness를 추가한다. 모든 맵의 UV 반복·회전·원점을 같이 맞춘다.
- 밉맵과 반복 샘플링을 사용하고 먼 거리에서는 기존 정점색/LOD와 자연스럽게 섞는다. JPEG 파일 크기가 작아도 GPU 메모리가 작다는 뜻은 아니다. RGBA8 기준 4K 한 장은 약64MiB, 밉맵 포함 약85MiB이고 8K는 약256/341MiB다. 1024px는 약4/5.3MiB다.
- displacement는 기본 런타임에서 끈다. 화면용 높이 맵으로 지면만 바꾸어 native2.5u 지형·보행·호수/도로의 높이 계약이 어긋나게 하지 않는다. 노멀은 시각 요철이며 보행 높이를 바꾸지 않는다.
- 미리보기의 구체 조명/그림자를 게임 색상으로 사용하지 않는다. 실제 연결 상태와 배포 파생본은 [텍스처 전체 안내](../../README.md)에서 관리한다.
