# dry_river_pebbles — 실제 4K 맵

상위 [재질 안내](../README.md)의 배치/스케일 기준을 공유한다. diff 전체와 중앙 확대를 직접 확인했다. 베이지·갈색·회색의 크고 작은 둥근 돌이 빈틈없이 모여 있고 일부 돌은 납작하고 짙다. 돌 사이 검은 틈과 표면 명암이 강해 멀리서는 대비가 큰 자갈무늬로 보인다. 같은 폴더에 구체/preview 이미지는 없다.

## 원본 구성

README 제외 이미지 **4개**, 모두 **4096×4096**이다.

| 파일 | 형식·정밀도 | 역할 |
|---|---|---|
| `dry_river_pebbles_diff_4k.jpg` | JPEG8비트 RGB | sRGB 확산/기본색. 게임 색상 맵 후보. |
| `dry_river_pebbles_nor_gl_4k.exr` | EXR · RGBA float16 | OpenGL 계열 탄젠트 노멀. 선형 데이터로 취급한다. |
| `dry_river_pebbles_rough_4k.exr` | EXR · Y float16 | 선형 거칠기. 밝을수록 거칠다. |
| `dry_river_pebbles_disp_4k.png` | PNG16비트 단일 성분 | 상대 높이. 중간값/물리 높이 단위는 확인되지 않았다. |

별도 AO/metallic/opacity 맵은 없다. 추가 파일이 있다고 가정하거나 없는 경로를 요청하지 않는다. 노멀 EXR은 RGBA float16이며 A채널이 있다는 이유로 자갈 재질의 투명도를 켜지 않는다. diff의 어두운 틈 위에 AO를 다시 강하게 곱하지 않는다.

## 반복·게임 용도·성능

한 타일2~4u를 시작값으로 권장한다. 큰 돌이 발보다 너무 커지지 않도록 근접 조정한다. 둥근 돌의 반복이 명확하므로 호안 전체보다 짧은 띠/패치에 사용하고 흙/잔디 경계와 섞는다. 원본 면적은 미확인이고 타일 무봉제성은 별도 검사하지 않았다.

농촌 개울 양옆의 마른 자갈톱, 큰/작은 호수 육지 호안, 짧은 해변 자갈 패치. 흐르는 물/호수 수면 자체가 아니라 바닥·마른 호안에 사용한다.

런타임은 diff512~1024px 파생본부터 시작한다. 노멀을 쓸 때만 EXR을 웹 재질용 선형 데이터 파생본으로 변환하고 축/색공간을 확인한다. JPEG/PNG의 밝은 색상 변환을 노멀 값에 적용하지 않는다. 원본 EXR과16비트 displacement는 기본 브라우저 이미지로 직접 연결하지 않는다. displacement는 기본적으로 끄며 보행 지형을 별도로 변형하지 않는다. RGBA8 4K한 장은 약64MiB, 밉맵 포함 약85MiB이므로 색상·노멀·거칠기를 전부 원본 크기로 올리지 않는다.

## 출처·라이선스 상태

파일명과 `diff/nor_gl/rough/disp_4k` 패키지 구성이 **Poly Haven 계열 배포본으로 추정**되지만 공급사 URL·제작자 정보·라이선스 원문은 폴더에 없다. 공급사 및 CC0 등 이용 조건은 원문 확인 전까지 확정하지 않는다. 웹 조회는 하지 않았다.


## 현재 런타임 반영

- `pebbles` → `natural-b.png`의 **B채널**. 원본 휘도 무늬를512px로 정규화하여 사용한다. RGB/PBR원본을 직접 연결하지 않는다.
