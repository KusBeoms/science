# dry_river_pebbles — 마른 하천의 조밀한 둥근 자갈

## 눈으로 확인한 스타일

diff 전체와 중앙 확대를 직접 확인했다. 베이지·갈색·회색의 크고 작은 둥근 돌이 빈틈없이 모여 있고 일부 돌은 납작하고 짙다. 돌 사이 검은 틈과 표면 명암이 강해 멀리서는 대비가 큰 자갈무늬로 보인다. 같은 폴더에 구체/preview 이미지는 없다.

## 원본 구성

README 제외 **5개**: `dry_river_pebbles_4k.blend`1개와 `textures/`의 이미지4개다. 파일 이름에 `.blend`가 붙은 이 경로는 디렉터리이며, 그 안에 같은 이름의 실제 Blender 파일이 있다. 이미지4개는 모두4096×4096이다. 상세 맵 역할/정밀도는 [textures/README.md](textures/README.md)에 기록했다. Blender 묶음 자체는 게임에서 직접 로드하는 재질 파일이 아니다.

## 반복·크기와 권장 위치

반복형 PBR 표면 후보이며 2×2 연결 경계는 별도 검증하지 않았다. 실제 촬영/스캔 면적은 미확인이다. 아래 u는 게임 시작 스케일이며 미터 단위의 원본 크기를 보증하지 않는다.

한 타일2~4u를 시작값으로 권장한다. 큰 돌이 발보다 너무 커지지 않도록 근접 조정한다. 둥근 돌의 반복이 명확하므로 호안 전체보다 짧은 띠/패치에 사용하고 흙/잔디 경계와 섞는다.

권장 위치: 농촌 개울 양옆의 마른 자갈톱, 큰/작은 호수 육지 호안, 짧은 해변 자갈 패치. 흐르는 물/호수 수면 자체가 아니라 바닥·마른 호안에 사용한다.

노멀 EXR은 RGBA float16이며 A채널이 있다는 이유로 자갈 재질의 투명도를 켜지 않는다. diff의 어두운 틈 위에 AO를 다시 강하게 곱하지 않는다.

## 게임에서 가볍게 쓰는 방법

- 원본 보관용 폴더다. 브라우저 배포에는 별도 512~1024px 색상 파생본부터 사용하고, 근접 검사에서 필요할 때만 2048px로 올린다. 원본 해상도 전체를 지형 청크마다 복제하지 않는다.
- 색상은 sRGB, normal/roughness/AO/height 같은 수치 맵은 선형 데이터로 취급한다. 색상 1장부터 공유 재질에 연결하고, 현재 재질이 해당 슬롯을 지원할 때만 normal·roughness를 추가한다. 모든 맵의 UV 반복·회전·원점을 같이 맞춘다.
- 밉맵과 반복 샘플링을 사용하고 먼 거리에서는 기존 정점색/LOD와 자연스럽게 섞는다. JPEG 파일 크기가 작아도 GPU 메모리가 작다는 뜻은 아니다. RGBA8 기준 4K 한 장은 약64MiB, 밉맵 포함 약85MiB이고 8K는 약256/341MiB다. 1024px는 약4/5.3MiB다.
- displacement는 기본 런타임에서 끈다. 화면용 높이 맵으로 지면만 바꾸어 native2.5u 지형·보행·호수/도로의 높이 계약이 어긋나게 하지 않는다. 노멀은 시각 요철이며 보행 높이를 바꾸지 않는다.
- 미리보기의 구체 조명/그림자를 게임 색상으로 사용하지 않는다. 실제 연결 상태와 배포 파생본은 [텍스처 전체 안내](../../README.md)에서 관리한다.
